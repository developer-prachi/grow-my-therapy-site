# Dr. Maya Reynolds, PsyD: Therapy Website

Grow My Therapy internship assignment.

## Built with

Next.js, React, Tailwind CSS and TypeScript.

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## What's included

- The homepage, with the same section order and layout as the original
- A new "Our Office" section
- A separate FAQs page
- A mobile menu and a "Request a session" pop-up form
- A light parallax effect on the quote photo

## Theme

"Evergreen & Terracotta": deep green, warm oat and terracotta.
